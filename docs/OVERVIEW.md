# invest2 — 미국주식 텔레그램 알림 봇 개요 (리뷰 요청용)

> 아래는 개인용 미국주식 정보 알림 봇의 설계 요약입니다. **각 기능의 설계(데이터 소스, 필터, 점수 기준)가 투자 정보로서 타당한지 평가하고, 보완할 점을 우선순위와 함께 제안해 주세요.** 마지막의 "검토받고 싶은 질문"도 참고해 주세요.

## 1. 전체 구조

- **실행 환경**: GitHub Actions (공개 저장소, Python 3.12 표준 라이브러리만 사용, 외부 패키지 없음)
- **실행 시각**: 매주 월~토 12:40 KST (미 동부 전날 23:40, 장 마감 후)
  - cron-job.org가 12:40에 GitHub API로 워크플로를 실행 (GitHub 자체 예약 실행은 지연·누락이 잦아 보조로만 사용)
  - 백업: GitHub 예약 실행 12:40 / 13:40 / 15:10. 그날 이미 보냈으면 바로 종료 (중복 방지)
- **전송**: 텔레그램 봇 → 개인 채널, HTML 포맷 메시지
- **상태 저장**: 실행 결과(일간 순위 스냅샷, 13F·내부자 처리 기록)를 저장소 `data/`에 JSON으로 커밋
- **비밀값**: 텔레그램 토큰·채팅 ID, SEC 연락처(User-Agent)는 GitHub Secrets

하루 최대 3종류의 메시지가 갑니다.

| 메시지 | 주기 | 파일 |
|---|---|---|
| ① 커뮤니티 화제 종목 (Reddit + StockTwits) | 화~토 일간 / 월 주간 종합 | `reddit_top10.py` |
| ② 13F 기관 포트폴리오 변화 | 관심 펀드가 새 분기 보고서를 낼 때만 | `sec13f.py` |
| ③ 내부자 매수 다이제스트 | 미국 공시일마다 1회 | `insider.py` |

## 2. 기능 ① 커뮤니티 화제 종목

**일간 (화~토)**
- **r/wallstreetbets Top 10**: ApeWisdom API(레딧 티커 언급 집계, 최근 24시간). 언급 수, 전일 대비 언급·순위 변화, 추천 수
- **🚀 WSB 언급 급증 Top 5**: ApeWisdom 상위 300개 중 오늘 언급 20회 이상이면서 전일 대비 2배 이상(또는 신규)인 종목, 증가량 순
- **r/dividends(배당주) Top 5**: ApeWisdom에 데이터가 없어 Reddit RSS로 최근 24시간 글·댓글(최대 약 500건)을 직접 수집해 미국 상장 티커(NASDAQ Trader 종목 목록) 언급 수를 셈
  - `$TICKER`는 그대로 인정, 대문자 단어는 상장 티커이면서 일반 단어/약어 제외 목록(IT, CEO, DRIP, YOC 등)에 없을 때만 인정
  - RSS에는 추천 수가 없어 언급 수만 표시. Reddit 요청 제한(429) 때문에 재시도 포함 약 3분 소요
- **📊 StockTwits 트렌딩 Top 5**: StockTwits 공개 API의 트렌딩 종목 + StockTwits가 제공하는 "왜 화제인지" 요약의 첫 문장을 한국어로 기계 번역
- 각 섹션에 서브레딧 설명 한 줄

**주간 (월요일)**
- 매일 저장한 상위 100개 스냅샷을 지난 7일치 합산 → WSB Top 10, 배당 Top 5 (언급 합계, 추천 합계, 언급된 일수)
- 주말 데이터는 수집하지 않음 (미국 기준 월~금 활동)

## 3. 기능 ② 13F 기관 포트폴리오 변화

- **대상**: 버크셔 해서웨이(버핏 → 그레그 에이블), 듀케인 패밀리 오피스(드러켄밀러), 틸 매크로(피터 틸)
- **데이터**: SEC EDGAR submissions API → 최신 13F-HR과 직전 분기 13F-HR의 보유 종목 XML 비교
- **표시**: 🆕 신규 편입(비중) · 📈 추가 매수 · 📉 일부 매도 · ❌ 편출(직전 비중) · 📊 비중 상위 5 (항목별 최대 5개)
  - 추가 매수/일부 매도 = 보유 **주식 수**가 10% 이상 변한 종목 (가격 변동만으로 인한 비중 변화와 구분), 직전 → 현재 비중을 함께 표시
- **처리 세부**
  - 금액 단위 자동 판별: 일부 펀드는 아직 천 달러 단위로 신고 → 주당 가격(value/주식수) 중앙값이 $1 미만이면 천 달러로 간주
  - 같은 종목의 주식/콜/풋은 별도 항목
  - 펀드별로 마지막에 알린 보고서 번호를 기록 → 새 분기 보고서가 올라올 때만 1회 전송
  - 270일 넘게 13F가 없는 펀드는 건너뜀
- **한계**: 13F에 티커가 없어 회사명으로 표시. 분기 말 기준 최대 45일 지연 정보. 롱 포지션만 보고됨(공매도·해외주식·현금 제외)

## 4. 기능 ③ 내부자 매수 다이제스트 (핵심 기능)

**데이터**: SEC EDGAR 일별 인덱스(form.YYYYMMDD.idx)의 Form 4 전체(하루 약 300~600건)를 파싱. 공시일 단위로 처리하고 마지막 처리일을 기록해 하루 1회만 전송. 공시 목록이 아직 게시 전이면 다음 실행에 묶어서 보냄.

**필터 (모두 통과해야 함)**
1. 거래 코드 `P`(장내 매수)만 — 옵션 행사(M), 보상(A), 세금 납부 매도(F), 일반 매도(S) 제외
2. 10b5-1(사전 약정 자동 매매) 표시된 신고 제외
3. 신고 1건의 매수 금액 $100K 이상
4. 직책: CEO, CFO(직함 문자열로 판별), 이사(isDirector)만. 10% 대주주·기타 임원 제외
5. 시가총액 $300M 이상 (Yahoo 현재가 × SEC XBRL 발행주식수)
6. 데이터 이상치 제거: 신고 매수가가 매수일 종가와 2배 이상 차이 나면 제외 (해외 통화 표기 오류 등)

**점수 (회사 단위로 합산, 상위 5개 전송)**

| 항목 | 점수 | 기준 |
|---|---|---|
| 금액 | 1~4 | <$250K / <$1M / <$5M / 그 이상 |
| CEO·CFO 매수 | +2 | 직함 기준 |
| 클러스터 | +3 | 최근 14일 안에 같은 회사 임원·이사 2명 이상이 각 $25K 이상 장내 매수 (10b5-1 제외). 과거 14일은 회사의 SEC 공시 목록에서 Form 4를 다시 조회 |
| 오랜만의 매수 | +2 | 해당 내부자가 직전 1년(최근 14일 제외) 동안 이 회사 주식을 장내 매수한 기록 없음 (내부자의 SEC 공시 목록 최대 30건 조회) |
| 하락 중 매수 | +1 | 매수가가 매수일 이전 52주 고점 대비 -20% 이하 |
| 보유량 대비 매수 | +1 / +2 | 기존 보유 주식 대비 +10% 이상 / +50% 이상 또는 신규 보유 (직접 보유 기준, Form 4의 거래 후 보유 수량으로 계산) |

**메시지 내용 (종목별)**: 티커·회사명·점수 / 🏢 업종(SEC SIC 분류) + 회사 소개 한 줄(Nasdaq 회사 프로필 첫 문장, 한국어 번역) / 매수 합계·시가총액 / 매수자 직책·이름·금액 / 매수일·신고일(3영업일 이상 지연 시 ⚠️) / 충족한 시그널 표시. 조건 충족 종목이 없으면 "오늘 의미 있는 내부자 매수 없음" 한 줄.

**실제 테스트 예 (2026-10-08 공시분)**: Form 4 306건 → 장내 매수 52건 → 조건 충족 2개 회사
```
1. $FUL FULLER H B CO — 점수 10
    🏢 접착제, 실란트 · 세계에서 가장 큰 pureplay 접착제 회사 인 H.B. Fuller의 혁신적이고 기능적인 코팅, 접착제 및 실란트는 품질을 향상시킵니다.
    💰 $500.0K · 시총 $2.7B
    👔 이사 Bailly R Jeffrey $500.0K
    📅 매수 10/07 · 신고 10/08
    👥 클러스터(14일 7명) · 🆕 1년+ 만의 매수 · 📉 52주 고점 -27% · 📦 신규 보유
```

## 5. 데이터 소스 요약 (모두 무료, API 키 없음)

| 용도 | 소스 | 비고 |
|---|---|---|
| WSB 언급 | ApeWisdom API | 전일 비교 포함 |
| 배당 게시판 | Reddit RSS | 공식 JSON API는 GitHub 서버 IP 차단, RSS도 429 잦음 |
| 트렌딩 | StockTwits 공개 API | 화제 요약 포함 |
| 13F / Form 4 / 업종 / 발행주식수 | SEC EDGAR (submissions, daily index, XBRL) | User-Agent에 연락처 필수, 초당 10회 제한 |
| 주가·52주 고점 | Yahoo Finance chart API (비공식) | |
| 회사 소개 | Nasdaq 회사 프로필 API (비공식) | |
| 번역 | Google 번역 비공식 엔드포인트 → 실패 시 MyMemory | GitHub 서버에서 Google 429 잦음 |

## 6. 알려진 한계

- 비공식 API(Yahoo, Nasdaq, Google 번역, StockTwits) 의존 → 언제든 차단·변경 가능
- 시가총액 = 현재가 × 발행주식수(최근 공시) → 다중 주식 클래스·ADR은 부정확할 수 있음
- Reddit 배당 게시판은 언급 수가 작아(일 3~20회) 순위 변동이 큼, 티커 추출은 사전 기반이라 오탐 가능
- 내부자 점수 가중치는 경험적 설정이며 백테스트로 검증하지 않음
- 공동 신고(여러 내부자가 한 Form 4)는 첫 번째 신고자만 사용
- 내부자 다이제스트는 하루 1~2분, 레딧 수집은 약 3분 소요

## 7. 검토받고 싶은 질문

1. 내부자 매수 필터와 점수 가중치가 학계·실무 근거에 비춰 타당한가? 빠진 강한 시그널이 있는가? (예: 매수 직후 실적 발표 일정, 업종 내 동시 매수, 공매도 비율)
2. 점수 상위 5개 방식 대신 더 나은 랭킹/노출 방식이 있는가?
3. 13F 변화를 볼 때 "주식 수 10% 변화" 기준이 적절한가? 추가로 보여줄 가치가 있는 지표는?
4. 커뮤니티 언급 지표(WSB 순위·급증, 배당 게시판, StockTwits)를 투자 판단 보조로 쓰려면 어떤 보정이나 추가 지표(가격·거래량 등)가 필요한가?
5. 비공식 API 의존도를 줄일 수 있는 무료 대안이 있는가?
6. 메시지 구성(정보량, 순서, 표현)에서 개선할 점은?
